# 闲鱼游戏本 · 低价筛选

按你的要求重做的版本：**只做游戏本、只认 N 卡、拿你自己的《笔电行情》表当参考价，低于表价 100 以上才看，卖家主页查骗子**。

它不爬详情页、不聊卖家、不下单——只负责“找出来 + 排好序 + 给链接”，剩下的你人工判断。

---

## 一分钟看懂它怎么筛

```
搜索（游戏本 3060 / 4060 / 2060 …）
  → ① 品类闸门：苹果、华为、轻薄本、工作站、台式显卡、无 N 卡 全部丢掉
  → ② 行情表比价：按「型号 + 显卡」匹配你表格里的收机价
  → ③ 价差底线：比表价低不到 100 的直接不看
  → ④ 打分排序：价差深度 + 显卡档位 + 品牌权重 + 新鲜度 - 想要人数 - 商家/骗子
  → ⑤ 卖家审核：主页出现大疆/无人机 → 直接排除；苹果设备多/回收号 → 减分
  → ⑥ 输出 links：reports/latest.html（可点）+ CSV + Markdown
```

## 筛选规则（完全按你的要求）

### 1. 只留游戏本，必须有 N 卡

- **排除**：苹果（MacBook）、华为（MateBook）
- **排除**：轻薄本、超极本、商务本、办公本、学生本、全能本、创作本、设计本、二合一、平板
- **排除**：工作站、移动工作站、Quadro / RTX A 系列专业卡
- **排除**：台式机显卡 / 配件（`8pin`、`单卡`、`三风扇`、“显卡+风扇/接口/供电”等特征）
- **必须有英伟达显卡**：标题里能识别出 GTX/RTX + 型号才进入下一轮；A 卡直接丢

标题里没有“笔记本”三个字时，还会用常见游戏本系列名兜底（拯救者 / 天选 / 蛟龙 / 战神 / 暗影精灵 / 掠夺者 / 雷神 / 机械师 …）。**认不出的就当台式显卡处理，不冒险。**

### 2. 品牌权重

| 品牌 | 处理 |
|---|---|
| 苹果、华为 | **直接排除** |
| 华硕（ROG/天选/飞行堡垒）、机械革命、联想（拯救者）、微星、神舟、七彩虹 | **+6 ~ +8 分** |
| 惠普、戴尔、宏碁、雷神、机械师、未来人类、技嘉、火影 | 0 分 |
| 其他 | 0 分 |

### 3. 行情表就是参考价

- 读你表格的 `名称 / CPU / GPU / 内存 / 硬盘 / 价格` 列，按 **显卡 + 型号名** 匹配；
- 匹配不到型号就用**同显卡档位的中位数**（比如 3060 的 10 条收机价中位数 ¥2,899）；
- 表里没有的显卡用相邻档位估算（3070 ≈ 3060 × 1.25，4070 ≈ 4060 × 1.3 …）；
- 标题写明 `4G/8G/32G 内存`、`128G/1T 硬盘` 时，会按配置对表价加减（4G −300、8G −150、32G +200…）。

**价差底线：低于表价 100 元才进打分。** 这条是硬门槛，不是扣分。

### 4. 显卡档位分

| 显卡 | 分数 | 显卡 | 分数 |
|---|---|---|---|
| 2060 | **+12** | 4060 | **+15** |
| 3050 / 3050Ti | **+10** | 4050 | **+12** |
| 3060 | **+14** | 3070 / 3080 | +7 |
| 2070 / 2080 | +6 | 4070 / 4080 / 4090 | +7 |
| 1660 / 1660Ti | +4 | 50 系（5050~5090） | **−10** |
| 1060 / 1070 / 1080 | 0 / +3 | 1050 / 1050Ti | **−25** |
| 1650 | −6 | | |

### 5. 骗子识别（看卖家主页）

对**分数靠前的少量商品**（默认 8 个），点进卖家主页看他在卖什么：

- 出现 **大疆 / DJI / 无人机 / Osmo** → **直接排除**（按你的规则：百分百骗子）；
- 卖 **3 件以上苹果设备**（iPhone/iPad/MacBook/AirPods）→ **−8 分**；
- 主页是“高价回收 / 实体店 / 质保 / 门头”，或 **在售 > 40 件 / 已售 > 500 件** → 判定商家，**再 −10 分**。

每个卖家只查一次，结果缓存 7 天，不会每轮重复打开。

### 6. 新鲜度 vs 想要人数

- 2 小时内上架 **+10**，6 小时内 **+7**，24 小时内 **+4**，3 天内 +1；
- 想要 ≥100 人 **−8**，≥50 人 **−4**（抢的人多，轮不到你压价）。

### 7. 商家

标题/昵称里带 `店铺 / 实体店 / 批发 / 回收 / 工作室 / 数码城 / 专营店 / 大量到货` → **−18 分**，主页再确认一次 → 再 −10。

## 打分公式（透明版）

```
分数 = 20（基础）
     + 价差分（0~40，按 低/表价 的比例给，低 100 是 0 分起点）
     + 显卡分（−25 ~ +15）
     + 品牌分（0 ~ +8）
     + 新鲜度（0 ~ +10）
     + 成色（全新/在保 +，磕碰/进水 −）
     − 想要人数（0 ~ −8）
     − 商家（−18，主页确认再 −10）
     − 卖苹果设备（−8）
```

- `≥80` 强烈推荐 · `≥68` 推荐 · `≥55` 可看 · 低于 55 不进报表
- 定金 / 进水 / 账号锁 / 坏机等，单独进「异常待核实」区，分数压到 35 以下

## 能力范围（确认，不是扩展）

你的主链条是：登录搜索 → 了解行情 → 筛选 → 聊卖家 → 下单 → 整备上架 → 买家沟通 → 提交发货。

**这个项目只覆盖其中两段：**

| 环节 | 状态 | 说明 |
|---|---|---|
| 1. 登录态搜索 | ✅ 已实现 | Chrome 扫码，复用登录态，自动翻页 |
| 2. 自动了解行情 | ⚠️ 静态 | 用你的 Excel 收机价，**不是**动态抓成交价；表要你自己更新 |
| 3. 按行情筛选 | ✅ 已实现 | 品类/显卡/品牌/价差/卖家审核/打分排序 |
| 4. 与卖家聊天 | ❌ 不做 | 闲鱼没有开放接口，模拟 IM 风险高、易封号 |
| 5. 下单 | ❌ 不做 | 涉及支付与账号安全 |
| 6. 整备后上架 | ❌ 不做 | 线下流程 |
| 7. 与买家沟通 | ❌ 不做 | 同上 |
| 8. 提交发货 | ❌ 不做 | 同上 |

**它就是一个“选品雷达 + 审核清单”，不是全自动店铺。** 第 4~8 步目前没有可靠且合规的自动化方式，建议保持人工。

其它已知边界：

- 型号匹配靠标题文字，卖家写错/不写型号时会退到“同显卡中位数”；
- 每轮最多审 8 个卖家的主页（`audit.max_items`），多了会很慢；
- 卖家审核只读主页在售列表，不点进每个商品；
- 详情页、实拍图、聊天记录都不解析；
- 行情表里没有的显卡用相邻档位估算，价格会粗一些。

## 配置怎么改

全在 `config.yaml`：

```yaml
scan:
  min_gap: 100      # 低于表价多少才看
  min_score: 55     # 进报表的最低分

audit:
  enabled: true     # 关掉可让扫描快 2 分钟
  max_items: 8

watches:            # 搜索词，按显卡档位搜
  - name: 游戏本 3060
    keyword: 游戏本 3060
    pages: 2
```

改完下一次运行立即生效。

## 常见问题

**行情表导不进去**
确认表头有 `名称` 和 `价格` 两列，且每个 sheet 是按显卡分的。导入失败会提示具体原因。

**一个都筛不出来**
先看终端打印的「排除原因」：如果是“比行情表还高”，说明现在挂牌价普遍高于你的收机价，这很正常；如果是“看不出是笔记本”，说明标题太简略，可以往 `watches` 里加具体型号词。

**提示 RGV587 / 抓不到**
风控。停 30~60 分钟；`run_scan.bat --headed` 看浏览器在做什么；或重新 `run_login.bat`。

**页面显示“非法访问”**
脚本已自动伪装 UA；仍出现就 `--headed`，或在 `config.yaml` 填 `browser.user_agent`。

**审核太慢**
把 `audit.enabled` 设为 false，或把 `max_items` 调到 4。

## 版本与回退

每个版本打一个 git tag，任何时候都能退回上一版。

```bash
git tag                    # 看所有版本
git checkout v1.0.0        # 回到某个版本（只读查看）
git switch -c fix v1.0.0   # 从某个版本开分支修
git show v1.0.0:xianyu/pricing.py   # 只看某版某个文件
```

发新版本（自动改版本号、写 CHANGELOG、提交、打 tag、推送）：

```powershell
powershell -ExecutionPolicy Bypass -File .\release.ps1 1.0.1 "修正 4060 中位价"
```

把线上退回某个版本（慎用，会改写历史）：

```bash
git reset --hard v1.0.0
git push --force-with-lease origin main
```

更安全的做法是 `git revert` 对应提交，保留历史。

## 合规

- 仅供个人选品比价，控制频率（≥15 分钟一次）；
- 不绕过验证码、不破解签名；
- 卖家主页只看公开信息，不抓联系方式；
- 交易走平台，别被“加微信私下交易”带走。

## 技术说明

- Python 3.12 + Playwright 1.64，复用本机 Chrome；
- 抓的是 `mtop.taobao.idlemtopsearch.pc.search`，登录态由真实浏览器发出，脚本只旁路读 JSON；
- 无头模式会自动替换 `HeadlessChrome` UA，否则闲鱼直接返回“非法访问”；
- 数据落在 `data\xianyu.db`（SQLite），审核状态、卖家审核缓存都在里面。
